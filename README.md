## Usage

### Install Dependencies

```
$ cd my-app

# with npm
$ npm install

# with yarn
$ yarn install

# with pnpm
$ pnpm install
```

### Use it

```
# development mode
$ npm run dev (or `yarn dev` or `pnpm run dev`)

# production build
$ npm run build (or `yarn build` or `pnpm run build`)
```
